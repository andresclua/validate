Up and running
in seconds

Call a validator with a value and a config. Get back isValid and an errorMessage. That's the whole API.

Read the docs → Form helper 
import { isEmail } from '@andresclua/validate'

const result = isEmail({
    element: input.value,
    config: {
        required: true,
        type: 'corporate',
        customMessage: { corporate: 'Use your work email.' },
    },
})

if (!result.isValid) {
    error.textContent = result.errorMessage
}
